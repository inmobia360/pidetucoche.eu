# Mapa de capacidades y skills opcionales

La lista aportada por el propietario es una recomendación, no prueba de instalación, seguridad o compatibilidad. Antes de usar una skill externa, comprueba que está disponible, revisa origen y permisos, fija versión cuando sea posible y solicita autorización si instalarla modifica el entorno.

## Mapeo por función

| Función | Skills/capacidades sugeridas | Alternativa cuando no estén disponibles |
| --- | --- | --- |
| Dirección y crítica | `grill-me`, `grill-with-docs`, `handoff`, `verification-before-completion`, `subagent-driven-development` | Plan, revisión documental, handoff estructurado y verificación manual |
| Descubrimiento | `find-skills` | Catálogo de skills disponible y búsqueda controlada |
| Producto y dominio | `domain-modeling`, `research` | Modelado explícito desde el pliego y fuentes primarias |
| Marca y UX | `frontend-design`, `web-design-guidelines`; `ui-ux-pro-max` solo tras revisión | Sistema Naranja Performance + auditoría WCAG |
| Frontend | `vercel-react-best-practices`, `frontend-design` | Documentación oficial del stack y pruebas de rendimiento |
| Backend/arquitectura | `tdd`, `improve-codebase-architecture`, `domain-modeling` | Pruebas, ADR y revisión modular local |
| QA | `webapp-testing`, `tdd`, `verification-before-completion` | Unitarias, integración, E2E y checklist UAT |
| Marketing | `seo-audit`, `copywriting`, `research` | Investigación con fuentes, revisión legal y analítica |
| Operaciones | `research`, navegador controlado, `handoff` | Procedimientos manuales y evidencias autorizadas |

## Reglas de selección

- Usa el conjunto mínimo que cambie materialmente la calidad del resultado.
- No instales todas las skills por anticipado.
- No concedas acceso a navegador, credenciales, archivos o red por popularidad.
- Una auditoría fallida o advertencia exige revisión humana y entorno aislado; puede justificar no usar la skill.
- No uses herramientas de scraping sobre AUTO1.com u otras fuentes sin autorización contractual y técnica.
- Las skills no sustituyen asesoría legal/fiscal, aprobación financiera, QA ni revisión de código.
