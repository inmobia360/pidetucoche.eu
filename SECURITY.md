# Seguridad

No publiques vulnerabilidades, credenciales ni datos personales en incidencias públicas.

Hasta que se habilite un canal privado formal, comunica un posible problema de seguridad directamente al propietario del repositorio mediante un canal privado acordado. Incluye alcance, reproducción, impacto y mitigación propuesta, evitando datos reales innecesarios.

Controles mínimos del proyecto:

- MFA para administración, compras y finanzas.
- Mínimo privilegio y RBAC.
- Secretos fuera de Git y de logs.
- Validación server-side y protección frente a abusos comunes.
- Webhooks firmados e idempotentes.
- Archivos con límites, tipo real, análisis y acceso firmado.
- Backups cifrados y restauración probada.
- Dependencias fijadas y revisadas.
